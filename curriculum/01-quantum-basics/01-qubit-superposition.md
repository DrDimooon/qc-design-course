# Кубит и суперпозиция (Qubit and Superposition)

## Кубит: определение

Кубит (qubit) — квантовая система с двумя различимыми базисными состояниями $|0\rangle$ и $|1\rangle$. В отличие от классического бита, который в каждый момент равен либо 0, либо 1, кубит может находиться в суперпозиции (superposition):

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \qquad \alpha, \beta \in \mathbb{C}, \quad |\alpha|^2 + |\beta|^2 = 1$$

В векторной записи (см. [модуль 00](../00-fundamentals/01-linear-algebra.md)):

$$|0\rangle = \begin{pmatrix}1\\0\end{pmatrix}, \qquad |1\rangle = \begin{pmatrix}0\\1\end{pmatrix}, \qquad |\psi\rangle = \begin{pmatrix}\alpha\\ \beta\end{pmatrix}$$

Физически кубитом служат: спин электрона (вверх/вниз), поляризация фотона (горизонтальная/вертикальная), два энергетических уровня сверхпроводящей схемы. Математика одна и та же.

## Нормировка и фаза: четыре числа → два угла

Четыре вещественных числа $(\alpha, \beta)$ после условия нормировки дают три степени свободы. Но глобальная фаза (global phase) $e^{i\gamma}$ невидима, поэтому остаются **две** вещественные степени свободы. Удобное представление:

$$|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\varphi}\sin\frac{\theta}{2}|1\rangle, \qquad \theta \in [0, \pi], \ \ \varphi \in [0, 2\pi)$$

Проверьте сами: нормировка выполняется автоматически, так как $\cos^2\frac{\theta}{2} + \sin^2\frac{\theta}{2} = 1$.

## Сфера Блоха (Bloch sphere)

Два угла $(\theta, \varphi)$ — сферические координаты: каждая точка единичной сферы соответствует чистому состоянию кубита.

| Точка сферы | Углы | Состояние |
|---|---|---|
| Северный полюс | $\theta = 0$ | $\|0\rangle$ |
| Южный полюс | $\theta = \pi$ | $\|1\rangle$ |
| $+x$ | $\theta = \pi/2, \varphi = 0$ | $\|+\rangle = \frac{\|0\rangle+\|1\rangle}{\sqrt2}$ |
| $-x$ | $\theta = \pi/2, \varphi = \pi$ | $\|-\rangle = \frac{\|0\rangle-\|1\rangle}{\sqrt2}$ |
| $+y$ | $\theta = \pi/2, \varphi = \pi/2$ | $\frac{\|0\rangle + i\|1\rangle}{\sqrt2}$ |

Ось $z$ — «классическое содержание» кубита: чем ближе к полюсу, тем предсказуемее измерение; на экваторе — максимальная случайность 50/50. Гейты — вращения сферы (об этом в [следующем уроке](02-gates-circuits.md)).

<details class="admonition analogy" markdown="1">
<summary class="admonition-title">Аналогия: стрелка на глобусе, но поворачивается целиком</summary>

Кубит — стрелка из центра глобуса: чем ближе к «северу» ($|0\rangle$), тем увереннее исход измерения, на экваторе — полный 50/50. Гейт — не тумблер, а поворот: H наклоняет стрелку с полюса на экватор, фазовые гейты крутят её вдоль долготы. Измерение спрашивает только «север или юг?» — и по широте стрелки получаешь шанс ответа. Предел аналогии: она про один кубит; для пары кубитов удобного «общего глобуса» нет — именно здесь начинается запутанность ([урок 03](03-entanglement-measurement.md)).

</details>

```python
from qiskit.quantum_info import Statevector
from qiskit.visualization import plot_bloch_vector

# состояние |+> в декартовых координатах сферы Блоха
plot_bloch_vector([1, 0, 0])   # (x, y, z) = (1, 0, 0)

# или из вектора состояния
sv = Statevector.from_label('+')
sv.draw('bloch')   # в Jupyter рисует сферу прямо в ноутбуке;
                   # в обычном скрипте окно не печатается в stdout — сохраните файл:
                   # sv.draw('bloch', filename='bloch.png')
```

## Измерение как проекция (projection)

Измерение в вычислительном базисе (computational basis) $\{|0\rangle, |1\rangle\}$ по правилу Борна:

$$p(0) = |\langle 0|\psi\rangle|^2 = \cos^2\frac{\theta}{2}, \qquad p(1) = |\langle 1|\psi\rangle|^2 = \sin^2\frac{\theta}{2}$$

Геометрия: $p(0)$ равна квадрату проекции вектора состояния на ось $z$. После измерения состояние коллапсирует (collapses) в $|0\rangle$ или $|1\rangle$ — суперпозиция в этом базисе потеряна навсегда.

Пример: для $|\psi\rangle = \frac{\sqrt{3}}{2}|0\rangle + \frac{1}{2}|1\rangle$: $p(0) = \frac{3}{4}$, $p(1) = \frac{1}{4}$.

```python
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
import numpy as np

qc = QuantumCircuit(1, 1)
qc.ry(np.pi/3, 0)     # поворот: theta = pi/3 => p(0) = cos^2(pi/6) = 0.75
qc.measure(0, 0)
counts = AerSimulator().run(qc, shots=10000).result().get_counts()
print(counts)   # примерно {'0': 7500, '1': 2500}
```

## Смена базиса: базис $\{|+\rangle, |-\rangle\}$

Базис не обязан быть $\{|0\rangle, |1\rangle\}$. Пара ортонормированных состояний $|+\rangle, |-\rangle$ — тоже полный базис. Любое состояние можно разложить:

$$|\psi\rangle = \gamma|+\rangle + \delta|-\rangle$$

Ключевой факт: относительная фаза (relative phase) **различима** в базисе $\{|+\rangle,|-\rangle\}$, хотя невидима в вычислительном. Пример: состояния $|+\rangle$ и $|-\rangle$ дают одинаковые вероятности 50/50 в базисе $\{|0\rangle,|1\rangle\}$, но после гейта H (который переводит между базисами) различие проявляется: $H|+\rangle = |0\rangle$, $H|-\rangle = |1\rangle$.

Таким образом, **измерение в другом базисе = поворот, затем стандартное измерение**. Смена базиса — не экзотика, а рабочий инструмент алгоритмов.

```python
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

qc = QuantumCircuit(1, 1)
qc.h(0)          # готовим |+>
qc.h(0)          # вторым H измеряем "в базисе {|+>,|->}"
qc.measure(0, 0)
print(AerSimulator().run(qc, shots=1000).result().get_counts())
# {'0': 1000} — H|+> = |0>: кубит был именно в |+>, а не в случайной смеси
```

Последний пример — ещё одно доказательство, что $|+\rangle$ — не «случайный бит»: классическая смесь 50/50 дала бы 50/50 и здесь.

## Что такое «суперпозиция» неформально

Точная формулировка: кубит — единичный вектор в $\mathbb{C}^2$. Интуиция: кубит несёт **непрерывное** количество закодированной информации (углы $\theta, \varphi$), но считывается лишь одним битом за измерение — в этом ограничение и источник мощности квантовых вычислений: обработка идёт в непрерывном пространстве, а извлечение результата — дискретное.

**Задание.** Проверьте в виджете, что формулы раздела о сфере Блоха действительно работают:

- Нажмите **H**. Точка встаёт на экватор, состояние |+⟩: θ = 90.0°, φ = 0.0°, P(0) = P(1) = 0.500, вектор Блоха x = 1.000, y = 0.000, z = 0.000.
- Не сбрасывая состояние, нажмите **T**: фаза станет φ = 45.0°, θ останется 90.0°, а вероятности по-прежнему 0.500 и 0.500 — фаза в вычислительном базисе не наблюдаема.
- Нажмите «Сброс |0⟩», затем **X**: точка переезжает на южный полюс, θ = 180.0°, P(1) = 1.000, P(0) = 0.000 — то есть чистое состояние |1⟩.
- Нажмите «Сброс |0⟩», затем **RX 90°**: точка уходит на экватор, θ = 90.0°, P(0) = P(1) = 0.500, а фаза становится 270.0° (то же самое, что −90°).

Как это связано с уроком: каждое движение точки — это ровно то, о чём шла речь выше: гейт есть поворот сферы, высота точки над горизонтом задаёт вероятности по правилу Борна, а долгота на экваторе — та самая относительная фаза, которую видно только в другом базисе. Для сравнения вместо **T** нажмите **S**: фаза станет 90.0°, и вероятности снова не изменятся.
