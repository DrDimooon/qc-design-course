# Онлайн-курсы

Справочник проверенных онлайн-курсов, организованный по принципу каталогов-эталонов (quantumcomputingcourses.com и разделы edX/Coursera): у каждой позиции указаны время прохождения, уровень, язык, тип (theory / hands-on / mixed), привязка к модулю курса (00–05, см. README репозитория) и наличие сертификата. Навигационные мини-таблицы «если нужен модуль N — вот курсы» — ниже, после основной таблицы. Нумерация модулей: 00 — фундамент, 01 — основы квантовых вычислений, 02 — программирование на Qiskit, 03 — алгоритмы, 04 — проектирование систем и компиляция, 05 — аппаратура.

- Тип: theory — лекции и текст без обязательного кода; hands-on — практика в notebook или на интерактивной платформе; mixed — смешанный формат.
- Сертификат: «да» — подтверждение предусмотрено на платформе (у IBM — значок Credly по результатам экзамена; у edX — платный verified-трек, аудит бесплатен; у openHPI в режиме самообучения — подтверждение участия).
- «Время» — ориентир по объёму; для недельных курсов указаны недели и часы в неделю.

## Примечания

- Все ссылки проверены вручную (webfetch) 18.10.2026: страницы открываются; у UChicago/Purdue/Delft контент подгружается скриптами, но заголовок курса и платформа подтверждены.
- Канонический домен курсов IBM Learning — `quantum.cloud.ibm.com/learning` (старый `learning.quantum.ibm.com` работает через редирект).
- Сертификацию IBM Learning удобно отличать по формату: учебник бесплатный, значок Credly выдаётся после прохождения экзамена курса на IBM Training.
- На edX бесплатные курсы доступны в режиме аудита; доступна проверка знаний и сертификаты — за плату.
- Курс UChicagoX выдаётся также как Professional Certificate Series «Quantum Computer Systems Design» (<https://www.edx.org/certificates/professional-certificate/uchicagox-quantum-computer-systems-design>), где три курса объединены в программу.
- openHPI-курс открыт в самообучении с 05.10.2022; в режиме self-study доступны видео и материалы, итоговый формат — только подтверждение участия (сертификат полноценного типа не выдаётся).
- Запись на курс МГУ — через платформу openedu.ru (ссылка «Запись на курс» на странице ЦКТ МГУ); наличие удостоверения на openedu не проверено.
- Длительности по IBM Learning — ориентир по времени прочтения текста (без упражнений и дополнительных кодов); недельные оценки по курсам edX — по данным страниц курсов на 2026 год.
- Связь с треками курса: IBM Learning / MSU / МФТИ–МИАН / IQM Academy покрывают общую базу 00–03; UChicagoX и CUDA-Q Academic — углубления 04; DelftX и Purdue II — 05.
