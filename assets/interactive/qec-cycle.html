Цикл коррекции ошибок: 3-кубитный код

Логический кубит psi = alpha|000⟩ + beta|111⟩ хранится в трёх физических кубитах. Внедряйте X-ошибку, измеряйте синдромы S1 = Z1 Z2 и S2 = Z2 Z3, декодируйте синдром в испорченный кубит и исправляйте ошибку. Кубит 1 — старший бит кета, кубит 3 — младший.

Как читать
  • Схема сверху. Три горизонтальные линии — дорожки физических кубитов: сверху кубит 1 (старший бит кета |q1 q2 q3⟩), в середине кубит 2, снизу кубит 3. Кружок с крестом — метка X-ошибки на этой дорожке. Справа два цветных блока: S1 = Z1 Z2 (объединяет кубиты 1 и 2) и S2 = Z2 Z3 (объединяет кубиты 2 и 3). Пунктирные линии показывают, какие дорожки затрагивает каждый стабилизатор. В блоке записано собственное значение оператора: +1 или -1, а до измерения стоит знак вопроса. После декодирования в блоке появляется подпись «ошибка: кубит N», а сама дорожка повреждённого кубита выделяется красным.
  • Полоса внизу схемы — цикл коррекции: измерение синдромов → декодирование → коррекция. Подсвеченный шаг показывает, на какой стадии находится виджет.
  • Код. Один логический кубит |psi⟩ = alpha|000⟩ + beta|111⟩. При выборе «Состояние |0⟩» получаем alpha = 1, beta = 0, при выборе «Состояние |+⟩» — alpha = beta = 1/sqrt(2). Информация лежит не в отдельном кубите, а в самой суперпозиции |000⟩ и |111⟩.
  • Синдромы. Стабилизаторы S1 = Z1 Z2 и S2 = Z2 Z3 — это операторы, которые одинаково действуют на обе компоненты кодового слова (дают +1), поэтому измеряют «целостность кода», а не данные. Синдром — это пара собственных значений (S1, S2). Классический код исправляет одиночную ошибку: ошибочный кубит находится по таблице (+1,+1) → ошибок нет; (−1,+1) → кубит 1; (−1,−1) → кубит 2; (+1,−1) → кубит 3.
  • Почему измерение синдромов не разрушает данные. S1 и S2 коммутируют с кодируемой информацией и с теми операторами, которые способны испортить код (X на любом кубите). Поэтому их измерение — не разрушающее: состояние остаётся тем же |psi⟩ = alpha|000⟩ + beta|111⟩, а «схлопывается» только невидимая информация о том, какой из восьми вариантов кода получен. В блоке состояния видно, что вектор до и после измерения совпадает: максимальное расхождение по компонентам равно нулю. Именно так и работает квантовый код: сохранить данные можно, скопировать их нельзя.
  • Почему нельзя просто «скопировать кубит». Теорема о неклонировании: неизвестное квантовое состояние нельзя скопировать в независимый кубит, потому что не существует универсальной операции U с U|a⟩|b⟩ = |a⟩|a⟩ для всех |a⟩. Если бы копия существовала, можно было бы измерить оригинал и получить всю информацию о произвольном состоянии — противоречие. Отсюда другой путь: не копировать, а перекодировать — разложить один логический кубит по трём физическим так, чтобы по измеренным синдромам можно было найти и отменить одиночную ошибку.
  • Предел кода. Минимальное расстояние кода d = 3, поэтому исправляется ⌊(d − 1)/2⌋ = 1 ошибка. Если внедрить две разные X-ошибки, одна коррекция уже не восстановит исходное состояние — виджет честно сообщает об этом в тексте.
  • Что делают кнопки. «Состояние |0⟩» и «Состояние |+⟩» заново кодируют логическое состояние и сбрасывают ошибки. «X-ошибка на кубит N» переворачивает один кубит. «Измерить синдромы» находит собственные значения стабилизаторов и декодирует синдром в номер испорченного кубита. «Исправить» применяет X к найденному кубиту и сравнивает результат с исходным вектором по всем восьми компонентам. «Сброс» возвращает виджет в начальное состояние.

Техническая заметка. Синдромы считаются не «на глаз» по амплитудам, а как собственные значения операторов: для каждого стабилизатора программно собирается матрица 8×8 (столбцы — образы базисных векторов под действием QC.GATES.Z через QC.sv.apply1), произведение операторов считается перемножением матриц, а собственное значение берётся по формуле Рэлея lambda = ⟨v|M|v⟩ / ⟨v|v⟩. Для кодовых состояний это ровно +1 или −1. Само измерение моделируется проекцией P = (1 + lambda·M)/2: для собственного состояния эта проекция тождественна, поэтому вектор состояния не меняется и данные остаются целыми. Виджет работает полностью офлайн (в том числе по file://), без внешних сетевых ресурсов: вся математика выполняется библиотекой assets/js/qc-core.js (QC.sv, QC.draw, QC.dom).
