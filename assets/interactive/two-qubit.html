Два кубита: суперпозиция, запутанность, корреляции

Наблюдайте, как меняются редуцированные состояния кубитов q0 и q1, вероятности совместных исходов и конкорренс состояния. Соглашение — как в Qiskit (см. CONVENTIONS.md): кет |q1 q0⟩, q0 — правый, младший бит. Базовый порядок амплитуд: |00⟩, |01⟩, |10⟩, |11⟩ (index = 2·q1 + q0).

Счётчики измерений

Как читать
  • Слева и справа — сферы Блоха отдельных кубитов. Для каждого кубита берётся редуцированное состояние: амплитуды суммируются по второму кубиту (след), и только затем строится вектор Блоха.
  • Сфера показывает редуцированные амплитуды кубита (сумма по второму кубиту), приведённые к норме. Для сепарабельного состояния это точная картина: после H на q0 (младший бит) указатель q0 лежит на экваторе (состояние |+⟩), а q1 остаётся на полюсе |0⟩ (вектор вдоль оси Z). После H на q1 картина обратная: на экваторе оказывается q1.
  • После «H на q0», затем «CNOT (q0 -> q1)» получается состояние Белла (|00⟩ + |11⟩)/sqrt(2). Это ровно `qc.h(0); qc.cx(0, 1)` в Qiskit: H на q0 даёт (|00⟩ + |01⟩)/sqrt(2), затем CNOT с управляющим q0 переводит |01⟩ в |11⟩. Если сначала сделать H на q1, q0 останется равным 0 и CNOT не сработает — запутанности не будет. Редуцированные амплитуды каждого кубита оказываются равными (0.7071 и 0.7071), но главный признак запутанности виден в строке «чистота редукции»: она равна 0.500, то есть по отдельности кубит полностью смешан (P(0) = P(1) = 50%), хотя пара в целом находится в чистом состоянии. Сфера сама по себе запутанность не описывает — её показывают конкорренс и запрет части исходов.
  • Исходы |01⟩ и |10⟩ в таком состоянии невозможны: при измерении обоих кубитов всегда получаются одинаковые биты (00 или 11), то есть корреляция 100%, хотя каждый кубит по отдельности даёт 50/50.
  • Конкорренс C = 2|a00 a11 - a01 a10| для чистого состояния двух кубитов: C = 0 — сепарабельное состояние, C = 1 — максимально запутано. В виджете порог запутанности — C > 0.1.
  • Гистограмма внизу — накопленные счётчики измерений: каждый клик по кнопке «Измерить 200 раз» добавляет 200 новых результатов (200 запусков одного и того же приготовленного состояния).
  • Кнопка «Сброс |00⟩» возвращает начальное состояние и одновременно обнуляет счётчики измерений. Кнопка «Сравнить» строит состояние |+⟩|+⟩ (H на обоих кубитах без CNOT): 25% на каждый исход, конкорренс 0, кубиты никак не коррелированы.

Техническая заметка. Соглашение о кубитах — как в Qiskit: кет |q1 q0⟩, q0 — младший бит, индекс = 2·q1 + q0, counts в том же порядке; полный справочник — CONVENTIONS.md в корне репозитория. Виджет работает полностью офлайн (в том числе по file://), без внешних сетевых ресурсов: вся математика выполняется библиотекой assets/js/qc-core.js (QC.sv, QC.bloch, QC.draw, QC.dom). Измерения здесь не схлопывают состояние-вектор — они эмулируют серию запусков одного приготовленного состояния; на реальном устройстве каждое измерение схлопывает состояние в один из базисных векторов. Расчёт конкорренса выполнен вручную по формуле C = 2|a00 a11 - a01 a10| для чистого состояния двух кубитов.
