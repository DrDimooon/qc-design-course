# Руководство по расписанию повторений

## Зачем это нужно

Прочитанный урок «отпускает» знания за считанные дни — так устроена память. Эталонное решение — [Quantum Country](https://quantum.country/qcvc) (Andy Matuschak, Michael Nielsen): карточки, встроенные в текст, и повторения по экспоненциально растущим интервалам. Авторы называют это «памятью как выбором» (memory is a choice): за несколько минут суммарного повторения на карточку вы удерживаете факт годами. Наша адаптация метода — колода [flashcards.md](flashcards.md) на plain markdown; здесь — правила её эксплуатации.

## Интервалы (упрощённый FSRS)

Каждая карточка живёт на одном уровне $l$ от 1 до 6:

| Уровень $l$ | Следующее повторение |
|---|---|
| 1 | через 1 день |
| 2 | через 3 дня |
| 3 | через 7 дней |
| 4 | через 14 дней |
| 5 | через 30 дней |
| 6 | через 90 дней |

Правила перехода:

1. **Правильно вспомнил** (быстро, без подсказок): $l \to l + 1$.
2. **Вспомнил с трудом, > 15 секунд или с подглядыванием в урок**: считайте ошибкой, $l \to l - 1$.
3. **Ошибся совсем**: $l \to l - 1$ (не в начало!) — по образцу Quantum Country интервал падает на одну ступень: след частично консолидированной памяти обычно сохраняется.
4. **Уровень 6 пройден успешно**: карточка считается «закрытой»; вернитесь к ней только перед экзаменами ([certification-quiz.md](certification-quiz.md), [final-exam.md](final-exam.md)).
5. Первое знакомство с карточкой происходит в момент чтения урока (знакомство «in-text», уровень 1 назначается со следующего дня) — так, как это делает Quantum Country.

## Правила сессий

- **Не более 20 карточек за сессию.** Ограничение не про объём: главный риск — деградация мотивации, а 20 карточек и так дают 5–10 минут.
- **Сессия почти ежедневно** (допустимо через день). Пропустили день — не «двойная норма» в следующий раз: проведите обычную сессию, отставшие карточки останутся due.
- **Чередуйте модули (interleaving)**: в одну сессию берите due-карточки из всех активных модулей, а не 20 подряд из одного.
- **Не знать — нормально.** Не вспомнили → откройте ответ, затем урок по ссылке из карточки, отметьте ошибку (правила 2–3 выше). Гадать нельзя: припомненное угадыванием не консолидируется.
- **Формулируйте ответ вслух или от руки** до открытия `<details>`: работает только режим извлечения (retrieval); чтение ответа со «похоже, да, я это знал» — не тест.

## Связь с PROGRESS и ROADMAP

Расписание из [ROADMAP.md](../ROADMAP.md) рассчитано на 8–10 часов в неделю; при таком темпе колода подключается по неделям так:

| Недели | Модуль / карточки | Событие в PROGRESS.md |
|---|---|---|
| 1–2 | 00 (8 карточек) | закрываются уроки 00 и квиз [tests/00-quiz.md](00-quiz.md) |
| 3–4 | 01 (9 карточек) | уроки 01 + [tests/01-quiz.md](01-quiz.md) |
| 5–7 | 02 (7 карточек) | уроки 02 + [tests/02-quiz.md](02-quiz.md) |
| 8–10 | 03 (10 карточек) | уроки 03 + [tests/03-quiz.md](03-quiz.md) |
| 11–14 | 04 (10 карточек) | уроки 04 + [tests/04-quiz.md](04-quiz.md) |
| 15–18 | 05 (11 карточек) | уроки 05 + [tests/05-quiz.md](05-quiz.md) |
| 19–20 | микс 00–05 | Certification quiz, далее — при желании final exam |

Этот план покрывает модули с повторениями (164 ч по [ROADMAP.md](../ROADMAP.md)).
Capstone-проекты (~120 ч, см. [projects/README.md](../projects/README.md)) идут
отдельно — параллельно последним неделям или после них, на ваш выбор.

Опережающие правила:

1. Карточки модуля подключаются к дневным повторениям в тот день, когда вы читали его уроки (первичное знакомство), — не раньше и не позже.
2. Связь с PROGRESS.md: правило «квиз пройден → закрыть пункт `- [x]`» остаётся; к нему добавляется порядок: урок → карточки (первичный прогон) → квиз.
3. Недели в таблице — ориентир. Считайте по due-карточкам, а не по календарю: расписание карточек самонесущее, недели служат только планированию объёма.

## Шаблоны личного журнала

Журнал ведите в личной заметке вне репозитория (например, `journal-flashcards.md` локально или в вашем персональном notes-блокноте). Ниже два шаблона — скопируйте и заполняйте.

### Шаблон А: журнал сессий

```markdown
## Журнал повторений

- [ ] С1 (дата): карточек 12, верных 12/12 — отметок нет
- [ ] С2 (дата): карточек 20, верных 18/20 — ошибки: 03.02 (l 3→2), 01.06 (осталась на l 1)
- [ ] С3 (дата): ...
```

### Шаблон Б: трекер уровней карт

| ID | Тема | 1d | 3d | 7d | 14d | 30d | 90d |
|---|---|---|---|---|---|---|---|
| 00.01 | Амплитуда и вероятность | - [ ] | - [ ] | - [ ] | - [ ] | - [ ] | - [ ] |
| 00.02 | Что даёт унитарность | - [ ] | - [ ] | - [ ] | - [ ] | - [ ] | - [ ] |

Как читать шаблон Б: столбцы — последовательные повторения уровней; при удачном повторении ставится дата, при неудаче — дата с пометкой «ошибка» (интервал сдвигается на уровень вниз). Строки добавляйте по карточкам активного модуля.

Пример заполненной строки: `| 00.04 | Глобальная vs относительная фаза | 18.10 | 21.10 | 24.10 (ошибка, l 4→3) | ... |`.

## Если хочется автоматизации: Anki

Наш формат — plain markdown с ручным расписанием, и это сознательный выбор: «память как выбор» работает и без аккаунта. Если всё же нужна автоматизация — Anki реализует тот же класс алгоритма бесплатно:

1. Установите [Anki](https://apps.ankiweb.net/) (desktop бесплатный, есть синхронизация на телефон).
2. В настройках колоды включите **FSRS** (встроен в Anki 23.10+): это тот же класс алгоритма, на котором построено наше руководство; desirable retention 0,85–0,9 даст интервалы, близкие к 1/3/7/14/30/90.
3. [AnkiConnect](https://ankiweb.net/shared/info/2055492159) (add-on 2055492159; домашняя страница проекта переехала на <https://git.sr.ht/~foosoft/anki-connect>, зеркало на GitHub — <https://github.com/FooSoft/anki-connect>) — REST-сервис на `localhost:8765` для программного добавления карточек и управления расписанием, если понадобится интеграция с CI или собственным скриптом.

### Экспорт колоды в TSV

Формат колоды машинно-разбираем: `### ID — тема`, затем `**Q:**`, затем ответ в `<details>`. Пример скрипта Python (сохраните его вне репозитория, например в `~/tools/flashcards_to_tsv.py`; в сам репозиторий скрипты этой ветки не входят):

```python
# flashcards_to_tsv.py: разметка flashcards.md --> TSV (id, Q, A) для Anki
# запуск: python flashcards_to_tsv.py [путь/к/flashcards.md] [--mathjax]
import re, sys, pathlib

src = pathlib.Path(sys.argv[1] if len(sys.argv) > 1 else "tests/flashcards.md").read_text(encoding="utf-8")
src = re.sub(r"`{3}.*?`{3}", "", src, flags=re.S)  # выкинуть code-блоки: в файле есть пример разметки
rows = []
CARD = re.compile(
    r"###\s+(\d{2}\.\d{2})[^\n]*\n\*\*Q:\*\*\s*([^\n]+)\n"
    r"<details[^>]*>\s*<summary>Ответ</summary>\n?(.*?)</details>",
    re.S,
)
for cid, q, a in CARD.findall(src):
    a = re.sub(r"Источник:.*$", "", a, flags=re.S)            # хвост источника
    a = re.sub(r"\[([^\]]+)\]\([^)]*\)", r"\1", a)            # ссылки -> текст
    a = re.sub(r"\s+", " ", a).strip()                        # одна строка
    q = re.sub(r"\s+", " ", q).strip()
    if "--mathjax" in sys.argv:                               # $...$ -> \(...\) для Anki
        q, a = (re.sub(r"\$([^$]+)\$", r"\\(\1\\)", s) for s in (q, a))
    rows.append(f"{cid}\t{q}\t{a}")
if not rows:   # ноль карточек — всегда сбой сбора, а не «успешный экспорт»
    sys.exit("0 карточек: проверьте формат — <details> может нести атрибуты "
             "(<details markdown=\"1\">), шаблон ищет именно это")
pathlib.Path("flashcards.tsv").write_text("\n".join(rows), encoding="utf-8")
print(f"exported {len(rows)} cards -> flashcards.tsv")
```

Тот же трюк одной заменой sed — если TSV уже экспортирован и нужно только перевести формулы `\$...\$` в формат MathJax для Anki:

```bash
sed -E 's/\$([^$]+)\$/\\(\1\\)/g' flashcards.tsv > flashcards-mathjax.tsv
```

Параметры импорта в Anki: File → Import → разделитель Tab; колонки 1 (ID) — пропустить или связать с полем комментария, 2 → Front, 3 → Back; включите «Allow HTML», если в ответах остались теги (их нет — но на будущее). Карточки отобразят LaTeX через `\(...\)`, если использовали флаг `--mathjax`.

## Границы подхода

Quantum Country встраивает карточки прямо в текст и берёт на свою инфраструктуру расписание и напоминания. Мы держим привязку проще — читайте урок, прогоняйте модуль, раз в день до 20 due-карточек по правилам этого файла, — и не обещаем автоматизации: то, что Quantum Country получает от аккаунта и email-напоминаний, здесь заменяет дисциплина. Дополнительный контекст о написании хороших вопросов — [andymatuschak.org/prompts](https://andymatuschak.org/prompts/).
