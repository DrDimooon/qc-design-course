## Вопрос 16 (модуль 04)
**Ответ: D.** Depth учитывает только длину критического пути и игнорирует **тип и надёжность** гейтов на этом пути: две схемы с одинаковым depth могут иметь разное число дорогих 2q-гейтов. Прокси-бюджет ошибки: $\varepsilon_{\text{схема}} \approx 1 - \prod_i f_i$ по гейтам, что для малых $\varepsilon_i$ близко к $\sum_i (1-f_i)$ (складываются вероятности отказа, а не «средние фиделити»), плюс readout-ошибка и idle-декогеренция $t/T_1, t/T_2$. Конкретные числа $f_i$ берутся из `Target`/свойств бэкенда и меняются от устройства к устройству; использовать формулу нужно как **оценку порядка**, а не как точный прогноз. Depth при этом остаётся удобной, но слабой метрикой.

## Вопрос 20 (модуль 05)
*Открытый вопрос.*
**Ответ (20 баллов):** метод — **interleaved RB**. Случайные последовательности Клиффорда длины $m$ прогоняются дважды: обычная RB (затухание $\alpha_{\mathrm{ref}}$ с декомпозицией в базовые гейты) и interleaved-вариант, где в каждую последовательность вставлен исследуемый гейт (затухание $\alpha_{\mathrm{int}}$). Ошибка гейта оценивается через **отношение** затуханий:
$$\mathrm{EPC} = \frac{d-1}{d}\left(1 - \frac{\alpha_{\mathrm{int}}}{\alpha_{\mathrm{ref}}}\right),$$
Здесь $d=2^n$, а $\alpha$ — параметр затухания кривой $P(m)=A\alpha^m+B$. В деполяризующей модели $\alpha=1-p$, и средняя ошибка на Клиффорд равна $r_{\mathrm{ref}}=\frac{d-1}{d}(1-\alpha_{\mathrm{ref}})$, а не $p$ без множителя. В interleaved-оценке применяется **отношение затуханий**, не отношение ошибок:

$$1-\frac{\alpha_{\mathrm{int}}}{\alpha_{\mathrm{ref}}}
=\frac{p_{\mathrm{int}}-p_{\mathrm{ref}}}{1-p_{\mathrm{ref}}},
\qquad p=1-\alpha.$$

Рубрика (по 5 баллов):

- Назван interleaved RB.
- Объяснены две серии измерений и отношение затуханий.
- Корректная формула оценки ошибки исследуемого гейта с множителем $(d-1)/d$.
- Указаны ограничения: статистика по нескольким длинам $m$, доверительные интервалы и модель шума. Формула точна в гейт-независимой деполяризующей модели; в общем случае это оценка с модельной неопределённостью. Если затухания почти совпадают, малая оценка ошибки может иметь большую **относительную** неопределённость — это требует интервала, а не отказа от тестирования хорошего гейта. Для классического Clifford-протокола исследуемый гейт также Clifford; non-Clifford требует подходящего расширения метода.

Ссылки: Magesan et al.; Qiskit Experiments (`InterleavedRB`). Минимальная численная проверка связи $\alpha$↔$r$:

```python
# qc: executable
from qiskit_aer.noise import depolarizing_error
from qiskit.quantum_info import SuperOp, average_gate_fidelity

lam = 0.06  # деполяризующий параметр p на Клиффорд: alpha = 1 - p = 1 - lam
for n_qubits, d in ((1, 2), (2, 4)):
    channel = SuperOp(depolarizing_error(lam, n_qubits))
    r = 1 - average_gate_fidelity(channel)      # средняя ошибка гейта
    alpha = 1 - lam                              # параметр затухания P(m) = A*alpha^m + B
    assert abs(r - (d - 1) / d * (1 - alpha)) < 1e-9   # r = (d-1)/d * (1-alpha)
    assert abs(r - (d - 1) / d * lam) < 1e-9      # r = (d-1)/d * p, НЕ r == p

# Interleaved: каждая пара "Клиффорд из ref + исследуемый гейт" даёт
# alpha_int = alpha_ref * (1 - p_g); EPC гейта = (d-1)/d * (1 - alpha_int/alpha_ref)
p_ref, p_g, d = 0.04, 0.10, 2
alpha_ref = 1 - p_ref
alpha_int = alpha_ref * (1 - p_g)
epc_g = (d - 1) / d * (1 - alpha_int / alpha_ref)
assert abs(epc_g - (d - 1) / d * p_g) < 1e-9
p_int = 1 - alpha_int  # при композиции p_int != p_ref + p_g
assert abs((1 - alpha_int / alpha_ref) - (p_int - p_ref) / (1 - p_ref)) < 1e-9
assert abs((1 - p_int / p_ref) - epc_g) > 0.01  # отношение ошибок не равно отношению затуханий
print("RB identities ok")
```

**Порог сдачи (сводно):** Part A — $A_{\text{верно}} \ge 7$ из 11 (точные баллы $175/11 \approx 15{,}91$/25), Part B — $B_{\text{верно}} \ge 4$ из 7 ($100/7 \approx 14{,}29$/25), Part C ≥ 15/30, Part D ≥ 12/20 и сумма ≥ 60/100. Если какая-либо часть ниже порога — экзамен не сдан независимо от суммы: это не даёт «вытянуть» итог за счёт одной сильной части.
