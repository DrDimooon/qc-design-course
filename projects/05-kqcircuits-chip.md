# Capstone: Дизайн топологии сверхпроводящего чипа в KQCircuits

## Цель

Ознакомительный, полностью виртуальный дизайн сверхпроводящего чипа в открытом CAD-проекте **KQCircuits** (IQM): собрать топологию из готовых элементов (CPW-резонаторы, волноводная readout-линия, ячейка для джозефсона), параметризовать частоты резонаторов, отрендерить результат в GDS/SVG. Фабрикация не требуется — только «на бумаге»: GDS-файлы как для виртуального fab-ready релиза.

## Что вы научитесь

- пользоваться KQCircuits: установка, структура проекта, иерархия KLayout-ячеек (Chip / Sample / Element);
- объяснять, что такое **CPW (coplanar waveguide) резонатор**: quarter-wave (λ/4), резонанс $f \approx v_p/4L$, фазовая скорость $v_p \approx c/\sqrt{\epsilon_\text{eff}} \approx 1.2\cdot10^8$ м/с на кремнии ($\epsilon_\text{eff} \approx 6.4$); как из целевой частоты вычисляется длина резонатора;
- различать добротности: $Q_{\text{ext}}$ (связь с readout-линией) и $Q_{\text{int}}$ (потери на TLS); связь $Q = \omega_r/\kappa$; как геометрия прокладки кабельных пар (cable pairing) влияет на $Q_{\text{ext}}$;
- параметризованный дизайн: элементы KQCircuits — параметризованные Python-классы, а не статическая геометрия;
- ввод/вывод: экспорт в GDS (виртуальный fab-ready файл) и SVG-превью.

## Пошаговый план

### Шаг 1. Установка и первый взгляд

```bash
pip install kqcircuits   # пользуется KLayout Python-модулем
```

Проверка: доступен CLI-инструмент `kqc`. Документация — официальная страница проекта на GitHub: <https://github.com/iqm-finland/KQCircuits> (организация `iqm-finland`, не `IQM-partners`), документация по API — <https://iqm-finland.github.io/KQCircuits/>. Рекомендуем сначала разобрать встроенные примеры чипов (reference designs в директории examples): они показывают ожидаемую структуру вызовов.

### Шаг 2. Структура чипа

Чипы описываются Python-классами (наследование от `Chip`). Зафиксируйте: размеры чипа, количество ячеек-кубитов, отступы. Изучите, какие параметры задаются (ширины, зазоры; имя чипа; выбранный тип junction).

### Шаг 3. Readout-линия + 4 CPW-резонатора

Соберите feedline; к ней привяжите четыре quarter-wave CPW-резонатора. Параметризуйте частоты: целевые $f_r$ = {6.0, 6.5, 7.0, 7.5} ГГц → длина $L = c / (4 f_r \sqrt{\epsilon_\text{eff}})$. Уточните в документации действующий параметр длины (в KQCircuits это обычно «length» у меандера) и приложите расчёт.

### Шаг 4. Связь Q_ext

Опишите (качественно) роль coupler: сколько «пальцев» overlap с feedline → больше ёмкость связи → больше $Q_{\text{ext}}$. Точный расчёт не обязателен, достаточно читабельного design-обоснования + ссылки на формулу $Q = \omega_r/\kappa$. Возле каждого резонатора добавьте qubit-ячейку (SQUID/junction-зона — отдельный sub-cell в KQCircuits).

### Шаг 5. Рендеринг и проверка

Экспортируйте проекты в GDS/SVG. Проверьте визуально: (а) резонаторы не пересекаются; (б) одинаковые зазоры; (в) ground-plane целостен (нет случайных рвов); (г) launcher-pad'ы по краям — как будущие точки bonding.

**Ввод/вывод проекта (что крутится между слоями):**

| Вход | Обработка | Выход |
|---|---|---|
| параметры (f_r, длина, зазоры, тип junction) | построение иерархии KLayout-ячеек | GDS-файл (fab-ready геометрия) |
| набор элементов (Element-классы) | параметризация → ячейки → чип | SVG-превью для чтения человеком |
| reference designs из examples | ваши модификации | design-отчёт (таблица параметров) |

Это типовой контракт любого CAD-флоу и то, за что в KQCircuits отвечают KLayout-слои масок: base metal, junction layer, marker layer и т.д. Найдите в проекте и перечислите хотя бы 3–4 таких слоя в отчёте — так вы поймёте, какие слои реально понадобятся на fab (см. [урок 04](../curriculum/05-hardware/04-cryogenics-fabrication.md)).

(точные API-вызовы сверяйте по документации вашей версии — интерфейсы KQCircuits периодически обновляются).

### Шаг 6. Дизайн-отчёт

README решения: ASCII-схема топологии, таблица параметров (target f_r, L_actual, оценка Q_ext, зазоры), скриншоты SVG, чек-лист «что эта схема требует от fab» (но без производства).

## Критерии приёмки

- [ ] KQCircuits установлен, скрипт генерации чипа запускается без ошибок.
- [ ] 4 CPW-резонатора с различной длиной под целевые частоты 6.0–7.5 ГГц.
- [ ] GDS и/или SVG рендерятся; приложены скриншоты.
- [ ] Отчёт содержит обоснование design-решений (частоты, Q_ext, зазоры) и этапы, которые fab выполнит.
- [ ] (bonus) Через Elmer-симуляцию KQCircuits посчитаны действующие частоты/`Q_ext` хотя бы одного резонатора и сопоставлены с аналитикой.

## Расширения

1. **Электромагнитная симуляция**: встроенный Elmer-модуль KQCircuits — посчитать резонансы по суммарной геометрии и сравнить с правилом $v_p/4L$.
2. **Другой reference-чип**: разобрать типичный пример (flip-chip, второй слой) в каталоге примеров проекта — какие дополнительные слои масок появляются?
3. **Свой элемент**: реализовать кастомный элемент (например, meander-резонатор) с соблюдением текущих правил CPW ширины/зазора.
