# Mapper starter: проверки без алгоритма решения

Это небольшой correctness-harness для [capstone 04](../../04-qubit-mapper.md), а не готовый router. Используется установленный стек курса (Qiskit/NumPy); отдельный пакет или MQT Bench не нужен. Создайте **свой** импортируемый модуль с callable:

```python
def route(qc, cm, seed):
    # Реализуйте алгоритм сами.
    raise NotImplementedError
```

Этот фрагмент — описание интерфейса, не исполняемый пример решения. В репозитории нет модуля-заглушки, который можно случайно принять за сданное решение.

## Контракт

- Вход `qc`: связанная по параметрам статическая унитарная `QuantumCircuit` с 1q/2q-инструкциями, без измерений, reset, barrier, delay и control flow. Исходный логический SWAP допустим. Высокоуровневые QFT/QV/3q-гейты предварительно разложите до этого домена.
- `cm`: симметричный `CouplingMap`, физических позиций не меньше логических. Начальное размещение **тождественное**: логический q начинает на физическом q. Неиспользуемые физические кубиты подготовлены в |0⟩. Несвязный граф допустим, если для нужных взаимодействий есть пути.
- Выход строго `(routed, phys)`: `routed` — физическая схема ширины `cm.size()` с тем же статическим 1q/2q-доменом; `phys[q]` — конечная физическая позиция логического q. Карта инъективна и содержит целые индексы допустимых проводов. Одних метаданных `routed.layout` недостаточно: физические qargs схемы должны быть правильными.
- Все выходные 2q-инструкции исполняются на рёбрах `cm`. Это симметричная абстрактная модель routing; нативный базис и исправление направленности CX проверяются в отдельном аппаратном pipeline.
- С учётом `phys` сохраняется действие на **всём** логическом пространстве с одной общей глобальной фазой, в том числе на суперпозициях. Дополнительные выходные провода вне `phys` остаются в |0⟩ для этого входного подпространства. Произвольные ненулевые входы ancilla здесь не проверяются.
- Входная схема и граф не изменяются. При одном seed и фиксированной конфигурации возвращается та же схема и карта. Схемы разных seeds не обязаны различаться; качество улучшаться не обязано.
- Невозможный вход (недостаточная ширина, направленный граф, недостижимое взаимодействие) или операция вне домена явно отклоняется через `ValueError`. Не возвращайте успешный результат с потерянными инструкциями.

## Запуск своего решения

Из корня курса, где ваш модуль импортируется как `my_mapper`:

```bash
python projects/starter/mapper/check_solution.py --module my_mapper
```

Можно использовать полное dotted-имя, например `student_solution.mapper`. Текущий рабочий каталог включается в путь импорта. Модуль должен экспортировать `route`; алгоритм не должен запускать benchmark при импорте.

`--module` обязателен: отсутствие аргумента, модуля/callable или ошибка контракта дают ненулевой exit code. Нет режима «решение не найдено, тесты пропущены, всё зелёное». Команда проверяет **ваш** код, а не автоматически подставленную реализацию из лабы.

Корпус ограничен 1–4 физическими кубитами: empty/дальнее взаимодействие/исходный SWAP/перенос 1q/лишний физический провод/достижимая часть несвязного графа, плюс **18** random circuits (2–4 кубита × 3 seeds × line/ring). Для каждого проверяются карта, смежность, отсутствие изменения входов, повторяемость и семантика. Семантическая проверка сравнивает все столбцы вложенного оператора с **единой фазой**, а не независимо подбирает фазу каждому базисному состоянию. Это ловит ошибки, которые не видны по одним вероятностям. Ни depth, ни SWAP-count, ни скорость не имеют «магического» ожидаемого числа.

## Проверка самого harness

```bash
python projects/starter/mapper/test_contract.py
```

Self-test извлекает `bfs_path`/`greedy_route` через AST из **существующего** [lab-05](../../../curriculum/04-systems-design/lab-05-sabre-routing.md), не копируя алгоритм в starter и не исполняя весь урок. Только в self-test адаптер ограничивает более широкий домен лабы до домена starter (например, отклоняет измерения). Это не тест вашего решения.

Self-test также проверяет принятие общей глобальной фазы и отклонение заведомо неверных routers: отсутствующего routing, потери гейта, неправильной карты, относительных фаз, неподдерживаемого выхода, изменения входа и молчаливого принятия неверного входа. Прохождение self-test не означает сдачу проекта: для своего решения нужен отдельный запуск с `--module` и собственный benchmark/отчёт по [рубрике](../../04-qubit-mapper.md#предметные-якоря-общей-рубрики).
